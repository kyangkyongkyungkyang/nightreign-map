# 나이트레인 시드 파인더

엘든링: 밤의 통치자(Elden Ring: Nightreign) 시드 식별용 인터랙티브 맵 도구.

세컨드 모니터에 띄워놓고, 밤의 왕 + 지변 + 낙하 지점 + 거점 건물을 선택하면 현재 시드를 특정합니다.

## 기능

- **밤의 왕 / 지변 선택** — 보스 8종, 지형 5종 조합으로 후보 축소
- **낙하 지점 선택** — 9개 스폰 위치 중 클릭하여 시드 후보 필터링
- **거점 식별** — 주요 거점의 건물 타입과 적 속성으로 시드 확정
- **시드 상세 보기** — 밤보스, 밤서클, 필드보스, 봉인감옥, 상인 등 전체 정보
- **보스 약점표** — 8종 물리/속성 경감률 + 6종 상태이상 내성치
- **필드보스 등급 구분** — 두려운 강적 / 강적 아이콘 분리
- **약점 매칭** — 선택한 보스의 약점 속성이 거점에 배치되면 초록 하이라이트

## 배포

정적 파일만으로 구성되어 별도 빌드가 필요 없습니다.

**GitHub Pages:**

1. 리포지토리 Settings > Pages
2. Source: `Deploy from a branch`
3. Branch: `main` / `/ (root)` 선택 후 Save
